# Morning Brew — Brand Identity System

> *"Where every morning becomes a ritual."*

A complete visual rebrand for **Morning Brew**, a neighbourhood artisan coffee shop.
Built for the **Rebrand a Local Coffee Shop** challenge.

## ✨ Features

- Cinematic loader with animated coffee bean
- Custom magnetic cursor with trailing ring
- Hero parallax + zoom-in on load
- Morphing blob image animations
- Mixed organic shapes across gallery
- SVG wave section transitions
- 3D perspective tilt on all cards
- Animated steam on cup mockups
- Scroll-triggered reveal animations
- Counting statistics
- Responsive at every breakpoint
- Mobile hamburger drawer menu
- Floating particle system
- Animated grain texture overlay
- Amber marquee ticker
